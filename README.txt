МИР ВОВКИ — прототип 0.3

Как открыть на iPhone/iPad:
1. Распакуйте ZIP в приложении «Файлы».
2. Для надёжного запуска откройте index.html через Safari (если iOS не предлагает Safari, сначала разместите папку на HTTPS-хостинге).
3. Озвучка использует встроенный голос iOS/Safari на русском языке; доступные голоса зависят от настроек устройства.
4. Это демонстрационный веб-прототип, не приложение App Store. Для установки как PWA нужен HTTPS-хостинг и отдельный manifest/service worker; для App Store — сборка и подпись iOS.

Звуки сейчас синтезируются голосом браузера. Настоящие записи животных, моторов и сирен ещё нужно добавить отдельно.
